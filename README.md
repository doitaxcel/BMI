# Adult BMI Calculator

A simple BMI (Body Mass Index) Calculator built using vanilla HTML, CSS, and JavaScript.

This application supports:
- US Customary Units
- Metric Units
- Dynamic UI switching
- Input validation
- BMI calculation

---

## Features

- Calculate BMI using:
  - Feet / Inches / Pounds
  - Centimeters / Kilograms
- Switch between US and Metric units
- Reset all input fields
- Restrict inputs to numbers only
- Responsive and clean UI

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

---

## BMI Formula

### US Customary Units

\[
BMI = \frac{703 \times weight(lbs)}{height(in)^2}
\]

### Metric Units

\[
BMI = \frac{weight(kg)}{height(m)^2}
\]
